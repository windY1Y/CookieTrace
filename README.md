# CookieTrace

This repository contains the artifact for our paper "xxxx".
Below we document the repository layout and the purpose of the main files and folders included in this repo.

- `cookietrace.patch`: Patch file for CookieTrace. We built prototype based on [Arcanum](https://github.com/BEESLab/Arcanum) (Chromium version 108.0.5359.71). Arcanum includes two patch files, CookieTrace is an implementation extending their `v8.patch`.

- `measure/`: Automation scripts used to run the experiments.

- `logs/`: Tracking logs generated by CookieTrace during experiment.

- `data_processing/`: Scripts used for processing raw experiment output (e.g., overhead computation, classification, characterizaiton...).

- `statistics/`: Statistical outputs and characterization results derived from the processed data, including analyses for both consent cookies and unnecessary cookies.
